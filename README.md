## 📘 Overview

The **Adaptive Microlearning Platform** is an **AI-driven e-learning system** that personalizes education through short, focused lessons and quizzes.  
It dynamically adjusts content difficulty, sequencing, and recommendations based on learner performance, ensuring **smarter, faster, and more engaging learning**.

This project combines three intelligent layers:

| Component | Description |
|------------|-------------|
| **Backend (FastAPI)** | Manages authentication, user data, and learning progress. |
| **Frontend (React)** | Provides a modern UI for learners and instructors. |
| **ML Service (Python/AI)** | Runs adaptive learning algorithms and analytics. |
